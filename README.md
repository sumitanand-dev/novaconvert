# 🚀 NovaConvert Engine

NovaConvert is a high-speed, 100% client-side file conversion and image compression web application built with pure Vanilla JavaScript.

## ✨ Features
- ⚡ Instant image conversion (PNG, JPG, WebP)
- 🔒 100% Private (All processing happens in the browser)
- 📱 Progressive Web App (PWA) Support
